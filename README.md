# ntx-msa-gateway

Atlas Link: servicio de gateway.

Este componente vive dentro del workspace `atlas-link` para que Maven lo compile junto con el módulo compartido `common`. Clona el workspace con `git clone --recurse-submodules https://github.com/jesusfranck09/atlas-link.git` y compílalo desde su raíz.

En el workspace: `mvn -f backend/pom.xml -pl ntx-msa-gateway -am package`.
